# Өлшем

Платформа для методистов: анализирует результаты тестирования школьников по темам, находит сложные разделы и их причины, честно сравнивает учебники и предлагает распределение учебных часов. Интерфейс на русском и казахском. Файлы с результатами обрабатываются в браузере и никуда не отправляются.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
```

```bash
npm run dev
```

Откройте http://localhost:3000. Приложение стартует на демонстрационных данных (все школы, ученики и учебники вымышлены). Свои результаты загружаются в разделе «Данные», там же есть пример файла.

```bash
npm test
```

## Сборка и выкладка

```bash
npm run build
```

```bash
npm start
```

Сборка статическая: всё приложение лежит в папке `out/` (около 1,5 МБ) и работает без сервера и без интернета. `npm start` раздаёт её на http://localhost:3000 без дополнительных пакетов. Чтобы выложить онлайн, папку `out/` можно перетащить в Vercel Drop или Netlify Drop, либо импортировать репозиторий в Vercel: он сам определит Next.js.

## Что внутри

| Требование кейса | Где | Как |
| --- | --- | --- |
| Анализ результатов по темам | `src/lib/engine/analyze.ts` | усвоение, относительная сложность, разброс классов |
| Сложные разделы | `src/lib/engine/analyze.ts` | для каждой темы называется причина: пробел в прошлой теме, учебник, часы, методика, программа |
| Сравнение учебников | `src/lib/engine/textbooks.ts` | поправка на входной уровень, погрешность по школам, поправка Бенджамини–Хохберга |
| Рекомендации по часам | `src/lib/engine/hours.ts` | убывающая отдача, частичное объединение оценок, оптимизация в рамках бюджета часов |

Демонстрационные данные (`src/lib/demo/generate.ts`) содержат заранее заданные истинные эффекты. Тесты проверяют, что система находит их сама.

Демо построено по структуре курса алгебры 8 класса обновлённого содержания: квадратные корни, квадратные уравнения, квадратичная функция, неравенства, статистика; 102 часа в год (3 часа в неделю).

## Файлы для живой загрузки

В папке `samples/` лежат три Excel-файла, сгенерированные с другими случайными зёрнами, чем встроенное демо:

| Файл | Что показывает |
| --- | --- |
| `1-normalnyy.xlsx` | обычная выгрузка: все столбцы на месте |
| `2-bez-vhodnogo-balla.xlsx` | нет входного балла: система предупреждает, что учебники сравниваются без поправки |
| `3-s-oshibkami-kz.xlsx` | казахские заголовки, баллы из 20 со столбцом «Ең жоғары балл», запятые в дробях, 60 пустых баллов, 35 баллов вне диапазона, 40 повторов: всё это отсеивается и показывается в отчёте |

## Настройки

Порог усвоения (по умолчанию 60 баллов) меняется на странице «Темы» кнопками − и +. От него зависят уровни тем, причины и план часов. Значение запоминается в браузере и печатается в протоколе.
