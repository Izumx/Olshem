# Өлшем

**Сайт: [olshem.vercel.app](https://olshem.vercel.app)**

Платформа для методистов: по результатам тестирования показывает, какие темы программы усваиваются хуже и почему, какой учебник действительно лучше учит и как перераспределить учебные часы. Интерфейс на русском и казахском.

Команда **IzanDuo** · Zhambyl Hub · Кейс 1 «Data-Driven Curriculum».

## Зачем

Методический совет каждый год решает, какой учебник закупать и сколько часов дать каждой теме. Обычно это делают по опыту и по рейтингу средних баллов. Средний балл обманывает: учебник, который выбирают сильные школы, выглядит лучшим, даже если учит хуже. Өлшем переводит такие решения на измеримые результаты учеников.

## Что умеет

| Раздел | Что показывает |
| --- | --- |
| Итоги | готовые решения для методсовета с обоснованием |
| Темы | уровень усвоения каждой темы, связи между темами и причину трудностей: пробел в прошлой теме, учебник, нехватка часов, методика или сложность программы |
| Учебники | сравнение классов с одинаковым входным уровнем; надёжность считается по школам |
| Часы | план перераспределения часов в рамках того же бюджета с прогнозом; часы можно двигать вручную |
| Протокол | документ для печати: решения, обоснования, ограничения |
| Данные | загрузка своих результатов в CSV или Excel |
| Метод | как считается и насколько точно, проверено на данных с известным ответом |

## Что видно на демо

Демо: 32 школы, 99 классов, 2 361 ученик, алгебра 8 класса, 12 тем, 102 часа. Все данные вымышлены.

- По среднему баллу первый Учебник A (67,6), но его чаще выбирают сильные школы. При равном входном уровне Учебник B лучше A на 4,5 балла, вероятный диапазон от 3,6 до 5,4.
- Сложных тем 6 из 12, и у каждой своя причина. Например, «Квадратные неравенства» усваивают 76% учеников, если усвоен «График квадратичной функции», и только 14%, если нет.
- Система переносит 6 часов внутри тех же 102: слабые темы прибавляют в среднем 1,4 балла. Сложные темы и темы, на которых они строятся, часы не теряют.

## Почему этому можно верить

В демо-данные заранее заложены настоящие эффекты, которых система не видит. На 10 смоделированных наборах она находит эффекты учебников с корреляцией 0,97 и эффект часов с корреляцией 0,94. Истинное значение попадает в 95-процентный интервал в 91% случаев. Тесты в репозитории проверяют это автоматически.

## Данные и приватность

Сервера нет: файл читается и обрабатывается в браузере и никуда не отправляется. Загруженный файл сохраняется только в этом браузере до возврата к демо.

Одна строка файла описывает одного ученика по одной теме. Заголовки распознаются на русском, казахском и английском.

| Столбец | Обязательный | Зачем |
| --- | --- | --- |
| Ученик | да | обезличенный код, не ФИО |
| Класс | да | |
| Учебник | да | |
| Тема | да | |
| Балл | да | от 0 до 100 или вместе со столбцом «Максимум» |
| Школа | желательно | честная оценка надёжности |
| Входной балл | желательно | поправка на силу школ |
| Часы | желательно | план распределения часов |
| Порядок темы, Максимум, Предмет | нет | |

Порог усвоения (по умолчанию 60 баллов) меняется на странице «Темы» кнопками − и +.

На странице «Данные» можно скачать пустой шаблон Excel (лист с примерами и инструкция на русском и казахском) и загрузить любой из файлов ниже одной кнопкой.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
```

```bash
npm run dev
```

Приложение откроется на http://localhost:3000.

```bash
npm test
```

### Сборка без интернета

```bash
npm run build
```

```bash
npm start
```

Сборка статическая: всё приложение лежит в папке `out/` (около 1,5 МБ) и работает без сервера и без интернета. `npm start` раздаёт её на http://localhost:3000.

### Выкладка на Vercel

```bash
npx vercel deploy --prod
```

Репозиторий к Vercel не подключён, поэтому после изменений эту команду нужно запускать заново.

## Устройство

Next.js 16, React 19, TypeScript. Вся статистика написана с нуля, без внешних библиотек.

| Требование кейса | Файл | Как |
| --- | --- | --- |
| Анализ по темам | `src/lib/engine/analyze.ts` | усвоение, относительная сложность, разброс классов, связи между темами |
| Сложные разделы | `src/lib/engine/analyze.ts` | для каждой темы проверяются пять объяснений по очереди |
| Сравнение учебников | `src/lib/engine/textbooks.ts` | регрессия с поправкой на входной уровень, погрешность по школам, поправка Бенджамини–Хохберга |
| Рекомендации по часам | `src/lib/engine/hours.ts` | убывающая отдача, частичное объединение оценок, перераспределение в рамках бюджета |

Остальное:

- `src/lib/demo/generate.ts`: демо-данные с заданными истинными эффектами;
- `src/lib/data/`: разбор CSV и Excel, сохранение в браузере;
- `src/lib/i18n.ts`: тексты на русском и казахском;
- `src/app/`: страницы;
- `docs/pitch.md`: сценарий защиты и ответы на вопросы жюри.

## Ограничения

- Выводы основаны на наблюдениях, а не на эксперименте. Связь между темами и эффект учебника служат поводом проверить, а не доказательством.
- Поправка учитывает только измеренный входной уровень. Качество учителя и условия школы могут остаться неучтёнными.
- Прогноз по часам не выходит за пределы часов, которые реально встречались в классах.
- Казахский текст интерфейса не вычитан носителем языка.
